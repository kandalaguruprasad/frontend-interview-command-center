# Frontend Quest

Level-based frontend interview prep game (React + Vite).

## Run

```bash
npm install
npm run dev
```

## Play loop

Home → **Continue Quest** → missions (Learn → Recall → Practise → Complete) → boss → Level Complete → next zone unlocks.

Progress is stored in `localStorage` under `ficc_quest_v1`.

## Legacy

Original single-file app lives in `legacy/index.html`. Data was extracted via `node scripts/extract-data.mjs`.
